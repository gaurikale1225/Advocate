# Adv. Bhagwan M. Awsare & Associates • Advocates & Legal Counsel

A modern, premium, responsive business landing page designed for an elite legal practice, law firm, and senior advocate chambers.

Built with clean HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, Bootstrap Icons, and AOS (Animate On Scroll).

---

## 🏛️ Features

- **Modern Navigation:** Sticky glassmorphism header with smooth scroll spy, mobile offcanvas navigation drawer, and direct appointment CTA.
- **Hero Showcase:** Full-viewport hero banner with rich typography, gold gradients, dual call-to-actions, and an interactive legal consultation badge.
- **Chambers Heritage & Counters:** Two-column advocate profile with real-time animated milestone statistics (cases represented, trust score, judicial honors).
- **Comprehensive Practice Areas:** Interactive practice area cards covering Civil Litigation, Criminal Defense, Corporate & Commercial Law, Real Estate & RERA, Family Law, and Arbitration.
- **Precedents & Track Record:** Tabular and structured milestone summaries representing landmark cases across the Supreme Court, High Court, NCLT, and RERA.
- **Why Choose Us:** Obsidian-themed luxury feature grid highlighting trial-tested acumen, transparent fee structures, rapid emergency response, and client confidentiality.
- **Inside the Chambers (Gallery):** Responsive media grid with category filters and an interactive vanilla JS lightbox preview.
- **Client Testimonials:** Testimonial carousel featuring client endorsements and star ratings.
- **Frequently Asked Questions:** Expandable accordion addressing initial consultations, fee structures, litigation timelines, and dispute resolution.
- **Direct Intake & Contact:** Validated case assessment form, quick-action WhatsApp button, direct calling, chambers address, and interactive Google Maps embed.
- **Floating Quick-Action Bar:** One-click WhatsApp consultation pulse button and smooth back-to-top scroll button.

## 💻 Tech Stack

- **HTML5:** Semantic markup, accessibility attributes, and SEO meta tags
- **CSS3:** Custom CSS variables, responsive fluid typography, flexbox/grid architecture, subtle keyframe animations
- **JavaScript (Vanilla):** Zero framework dependencies; handles sticky navbar, counter animations, gallery filtering, lightbox modal, and WhatsApp URL dispatch
- **Bootstrap 5.3.3:** Responsive grid system and utility classes via CDN
- **Bootstrap Icons 1.11.3:** Vector icon set via CDN
- **AOS (Animate On Scroll):** Lightweight scroll-reveal animations via CDN
- **Google Fonts:** *Cinzel*, *Playfair Display*, and *Plus Jakarta Sans*

## 🚀 Getting Started

Simply clone the repository and open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/gaurikale1225/Advocate.git

# Navigate into the project folder
cd Advocate

# Open index.html in your browser
# On Windows:
start index.html
# On macOS:
open index.html
# On Linux:
xdg-open index.html
```
